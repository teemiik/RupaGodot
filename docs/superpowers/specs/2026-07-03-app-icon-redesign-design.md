# Дизайн-документ: новая иконка приложения «Rupa»

- **Дата:** 2026-07-03
- **Статус:** утверждён (вариант A1, полная проводка)
- **Проект:** RupaGodot (Godot 4.6), пакет `com.circlesandholes.game`, название «Rupa»

## Контекст и цель

Текущая иконка (`assets/icon.png`) — объёмная фотореалистичная дыра в каменной стене. Она не согласована с лёгким визуальным языком игры (мягкие тёплые градиенты, круг/шар и отверстие) и тяжеловесна на мелких размерах.

Цель — сгенерировать новую иконку в выбранном направлении **A1 «Мягкий градиент»**: минималистичная плитка в фирменной тёплой палитре с отверстием и шаром, рассказывающая суть игры (шар проходит отверстия). Иконка должна читаться на размерах от 58×58 (iOS settings) до 1024×1024 (App Store) и корректно работать с адаптивными масками Android.

## Финальный дизайн (A1)

Композиция описана в нормализованном поле **200×200**; при растеризации масштабируется с коэффициентом `size/200`.

- **Плитка:** скруглённый квадрат (squircle). rounded rect `x6 y6 188×188 rx44`.
  - Чистый вертикальный градиент фона: `#CCC2AD` (верх) → `#85212E` (низ). Верхнее свечение убрано по просьбе заказчика (плоский градиент).
- **Отверстие:** круг `cx100 cy108 r46`, радиальный градиент `0.5→#0c0c0e … 1→#221318`.
  - Кайма-рулайт: эллипс `cx100 cy108 rx48 ry48`, обводка `#F5E6C7`, толщина `2.5`, непрозрачность `0.5`.
  - Внутренняя тень: эллипс `cx100 cy98 rx44 ry15`, чёрный, непрозрачность `0.45`.
- **Шар:** глянцевая сфера на верхнем правом краю отверстия.
  - Тень контакта: эллипс `cx132 cy94 rx17 ry6`, чёрный, непрозрачность `0.28`, размытие.
  - Шар: круг `cx132 cy75 r16`, радиальный градиент `0→#ffffff … 0.55→#CCCCD4 … 1→#8f8f97`.

Палитра взята прямо из игровых переменных (`bg_warm_top`, `bg_warm_bottom`, `bg_warm_glow`, `ball_color`, `hole_color` в `scripts/game.gd`).

## Артефакты

| Файл | Размер / формат | Назначение |
|---|---|---|
| `assets/icon.svg` | вектор | мастер-источник (читаемый, редактируемый) |
| `tools/generate_icon.py` | скрипт | генератор на Pillow; из одних параметров собирает все PNG (воспроизводимо) |
| `assets/icon.png` | 1024×1024, squircle | заменяет текущий → `project.godot` `config/icon` + Android `main_192x192` |
| `assets/icons/ios_1024.png` | 1024×1024, full-bleed квадрат (без скругления) | `export_presets.cfg` → `icons/icon_1024x1024` |
| `assets/icons/android_fg_432.png` | 432×432, прозрачный фон, мотив в центральной safe-zone (~66%) | `launcher_icons/adaptive_foreground_432x432` |
| `assets/icons/android_bg_432.png` | 432×432, full-bleed градиент | `launcher_icons/adaptive_background_432x432` |

**Адаптивная иконка Android:** фон = полный градиент (маскируется системой); передний план = группа «отверстие + шар», отцентрированная и вписанная в центральный круг диаметром ~66% (≈285px из 432), чтобы маски (circle/squircle/...) не обрезали мотив.

**iOS 1024:** full-bleed квадрат (iOS сам накладывает superellipse-маску) — без ручного скругления и без прозрачности.

## Метод сборки

Растровых SVG-конвертеров на машине нет (`rsvg-convert`/ImageMagick/`cairosvg` отсутствуют), но есть **Pillow 11.0**. Поэтому:

1. `tools/generate_icon.py` рисует все PNG средствами Pillow (линейные/радиальные градиенты, круги, эллипсы, размытие для теней/свечения) из единого набора параметров композиции A1.
2. `assets/icon.svg` хранится как читаемый мастер-источник дизайна; PNG — собранные артефакты.

Так палитра и геометрия получаются пиксельно точными, а пересборка любых размеров — одной командой.

## Проводка в конфигах

- **`project.godot`** — без изменений: `config/icon="res://assets/icon.png"` (заменяется сам PNG).
- **`export_presets.cfg`**:
  - iOS (preset 0): `icons/icon_1024x1024="res://assets/icons/ios_1024.png"`.
  - Android (preset 1): `launcher_icons/adaptive_foreground_432x432="res://assets/icons/android_fg_432.png"`, `launcher_icons/adaptive_background_432x432="res://assets/icons/android_bg_432.png"`. `main_192x192` уже указывает на `res://assets/icon.png`.
  - `application/icon_interpolation=4` (Lanczos) — без изменений.

## За рамками (out of scope)

- Редизайн UI/геймплея игры.
- Эмблемы, лого, иконки витрин магазинов (App Store Connect / Play Console) — грузятся отдельно из того же 1024-мастера.
- Монохромная адаптивная иконка Android 13+ (`adaptive_monochrome_432x432`) — осознанно не делаем (может быть добавлена позже отдельной задачей).

## Принятые решения

- Направление: **A1** (выбрано пользователем из 4 направлений, затем из 3 уточнённых вариантов).
- Охват: **полная проводка** (без монохрома).
- Метод: **Pillow-генератор + SVG-мастер** (обусловлено отсутствием SVG-конвертеров).
